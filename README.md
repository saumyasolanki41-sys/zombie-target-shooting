# 🧟 Zombie Attack — Top Down Survival

🎮 **Live Game:** https://zombie-target-shooting-game.vercel.app/

A browser-based top-down zombie survival shooting game developed using HTML, CSS, JavaScript, and HTML5 Canvas.

## 🚀 Play the Game

👉 **[Click here to play Zombie Attack](https://zombie-target-shooting-game-in.vercel.app/)**

The game is deployed on Vercel and can be played directly in a web browser without any installation.

---

## 🎮 Game Features

- 🧟 Zombie wave-based survival
- 🔫 Multiple weapons
- 🎯 Mouse-based aiming and shooting
- 🔄 Reload system
- ❤️ Player health system
- 📦 Weapon and power-up pickups
- ⚡ Speed Boost
- 💥 Damage Boost
- 🛡️ Shield Power-up
- 📊 Score tracking
- 🌊 Increasing zombie waves
- 🔊 Game audio
- 🌿 Top-down game environment

---

## 🕹️ Controls

| Action | Control |
|---|---|
| Move | `W A S D` / Arrow Keys |
| Aim | Mouse |
| Shoot | Mouse Click |
| Reload | `R` |
| Pistol | `1` |
| Shotgun | `2` |
| SMG | `3` |

---

## 🔫 Weapons

### Pistol
Starting weapon with balanced damage and ammunition.

### Shotgun
Close-range weapon that fires multiple pellets.

### SMG
Fast-firing weapon with a larger magazine.

Weapons can be unlocked by collecting weapon pickups.

---

## 📦 Power-Ups

- ⚡ **Speed Boost** — increases movement speed
- 💥 **Damage Boost** — increases weapon damage
- 🛡️ **Shield** — protects the player from damage

---

## 🧟 Gameplay

1. Start the game.
2. Move using `WASD` or arrow keys.
3. Aim using the mouse.
4. Shoot incoming zombies.
5. Reload when needed.
6. Collect weapons and power-ups.
7. Survive the zombie waves.
8. Keep increasing your score.
